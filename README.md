# 研析 · 基线统计

打开即可使用的临床基线统计网页。无需注册或安装 R，文件和计算结果仅在当前浏览器内存中保留，不上传到服务器；关闭或刷新页面前请下载需要保留的结果。

功能包括 Excel/CSV/TSV 导入、两组及多组独立观测的描述与探索性比较、变量类型及等级确认、自动展示均值（SD）或中位数（Q1，Q3）、组内 Shapiro–Wilk 和方差筛查，以及 Word、Excel 与分析记录导出。

本仓库只包含网页源码、运行组件和 12 条合成示例数据，不包含任何患者数据或用户账号。数据文件最大 20MB，每次最多 100 列、10000 条记录。首轮计算需要下载运行组件及 R 包，请使用新版浏览器并保持网络连接。

统计引擎的 69 项回归检查已在 webR 中通过；使用者仍需核对研究设计、变量类型和最终分析方法。配对、重复测量和整群研究不适用。

运行组件：webR 0.6.0（R 4.6.0）、jsonlite 2.0.0；导入导出依赖 SheetJS 0.20.3（npm @e965/xlsx 再分发）及 docx 9.12.0。各第三方许可随 vendor 文件保留。
