# 研析 ClinStat · 临床统计

打开即可使用，无需注册或安装 R。Excel/CSV/TSV 在浏览器中读取与计算，不上传患者数据；关闭或刷新前请下载结果。首次计算需联网加载 webR 和相应 R 包。

- 基线分析：两组及多组独立观测，确认变量类型、等级和展示口径，分布诊断及探索性比较，导出 Word、Excel、分析记录。
- 重复测量结果：打开 `longitudinal.html`；两组至十组，一行一名患者，单结局2–8个分类时间点、最多8项结局。各结局须完整测量，缺失会明确提示，不插补、不静默删人。
- 连续／近似连续结局：Gaussian identity GEE 或患者随机截距 LMM，比较均值差。
- 二分类：指定实际事件值，Logistic GEE 或随机截距 GLMM，报告事件 OR。
- 有序分类：声明实际等级从低到高的顺序，累积 Logistic GEE 或随机截距 CLMM，报告更高等级共同 OR。比例优势假设需另行核对。
- 重复测量结果分开呈现原始描述与模型估计；含组别、时间、交互联合检验、时点内组对比较、Holm校正及逐项95%CI。支持 Word、Excel、JSON 和 SVG 图下载。

GEE 使用患者聚类稳健方差；分类 GEE 使用独立工作相关。LMM 使用 REML、containment自由度；分类混合模型使用Laplace近似，其概率为随机截距设为0的条件预测。不会通过一次正态性检验自动选择模型。暂不支持缺失数据建模、额外协变量、中心／家庭等额外聚类、有限样本GEE修正或自动比例优势诊断。当前用于探索性分析，仍需研究者确认设计与模型假设。

本公开目录只含网页源码、运行组件、12条基线合成记录及240条重复测量合成记录，不含患者数据或账号。基线最多10000条记录；重复测量最多5000名患者（有序模型另有规模限制）；文件最大20MB、100列。

运行组件：webR0.6.0 / R4.6.0，jsonlite2.0.0，geepack1.3.13、nlme3.1.171、lme4 2.0.6、ordinal2026.7.26（按模型加载）。SheetJS0.20.3、docx9.12.0负责导入导出；第三方许可随vendor保留。资源使用相对路径，兼容GitHub Pages项目子路径。
